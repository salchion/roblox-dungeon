# 세트 효과 창(Y): 이 세팅에 맞게 장비 자동 장착 (시안 · 코드 미반영)

그림: `aug-autoequip-preview.svg` (1200 x 1300, 이모지 없음)

- 요청: 세트 효과 칸에 1구역 / 3구역을 끼웠으면, 버튼 하나로 그 효과 단계가 최대가 되게 장비를 알아서 끼워 달라.
- 대상: 지금 세팅(사냥용 / 보스용)의 칸에 끼운 효과만.
- 점수: 1순위 끼운 효과 단계 합(효과마다 최대 6) → 2순위 세트 2 / 3부위 능력치 보너스 → 3순위 장비 점수 합.
- 방어 효과(방벽 등)는 세트 장비가 없어 '+1' 옵션 장비만 센다.
- 계산: 부위마다 후보(세트별 / 옵션별 최고 1개 + 그냥 최고 1개)만 남겨 6부위 모든 조합 비교.
- 기존 장비 창의 '최강 장비' / 세트 버튼은 그대로 둔다 (효과 칸 / '+1' 옵션을 모른다).
- 구현 예정: `Inventory.EquipForAugs(player, zones)` (서버) + Y 창 버튼 / 결과 줄 (`AugClient`).
