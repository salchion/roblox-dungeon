# 던전 드래프트: 이미 고른 강화 표시 (시안 · 코드 미반영)

그림: `draft-owned-preview.svg` (1200 x 1000, 이모지 없음)

- 같은 갈래(폭발 / 연쇄 / 관통)나 같은 퍼크를 또 고르면 단계가 오르는데, 앞에서 뭘 골랐는지 외우기 어렵다는 의견 (롤 증강 세트 표시 참고).
- 카드 왼쪽 위 리본: 이미 가진 수 ("보유 x1", "2단계 보유"). 처음 보는 카드는 리본 없음.
- 카드 아래 단계 점: 채운 점 = 이미 가진 단계, 흐린 점 = 이번에 고르면 오를 단계. 갈래는 4번째 점 = 최종 기술.
- 갈래 카드는 바깥 빛 테두리, 그 카드를 가리키면 위 덱 줄에서 같은 갈래 칸이 반짝.
- 구현 시: 서버(`Dungeon.OfferChoice`)가 카드마다 보유 수 / 최대 / 다음 단계 이름을 같이 보내고, `RunChoiceClient` 가 리본 / 점을 그린다.
