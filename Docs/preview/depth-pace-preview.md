# 던전 깊이 창: 예상 보스 처치 시간 (시안 · 화면 코드 미반영)

그림: `depth-pace-preview.svg` (1200 x 1240, 이모지 없음)

- 문제: 처음 세팅하면 10단계쯤 깨지만, 그다음 몇 단계까지 갈 수 있는지 가늠이 안 된다 (깊이마다 체력 x1.22).
- 해결: 깊이를 고르면 "예상 보스 처치 N초"를 보스 제한 60초와 비교해 신호등으로 보여 준다.
  - 초록 = 30초 이하(여유) · 노랑 = 60초 이하(빠듯) · 빨강 = 제한 초과
  - 계산: `Config.Dungeon.PaceEstimate` = 기록 초 x 1.22^(깊이 - 기록 깊이) x (기록 때 전투력 / 지금 전투력)
  - 깊이별 띠(앞뒤 몇 칸), "추천 깊이" 버튼 = 열린 깊이 중 60초 안에 깰 수 있는 가장 깊은 곳
  - 기록이 없으면 "한 판 깨면 예상 시간이 나와요"
- 이미 반영(코드): `Server/DepthPace.lua` 가 보스를 잡을 때 깊이 / 혼자 기준 처치 초 / 전투력을 저장(MetaService `Pace`, Attribute `PaceDepth` / `PaceSecs` / `PacePower`)하고 Studio 에 `[던전 기록]` 로그를 찍는다.
- 남은 것: 이 시안 확인 후 `DungeonDepthClient` 화면.
