# 타격감 패스 시안 (미리보기 전용 · 코드 미반영)

그림: `hitfeel-preview.svg` (1200 x 1800, 이모지 없음 · 폰/PNG 변환용)

배지: **기존**(초록) = 지금 코드에 이미 있는 연출 · **변경**(노랑) = 있는데 값만 바꿈 · **신규**(주황) = 새로 넣을 것.
흔들림 값은 `PlayerClient` HitShake 의 값(초당 2.5 감소: 0.35 -> 0.14초, 0.5 -> 0.20초).

| 프레임 | 지금 (근거) | 적용 후 시안 |
|---|---|---|
| 1 일반 명중 | 흰 숫자 팝 1.35(가로로 납작) -> 1.0 / 0.14초, 수명 0.5초 (`FxClient` D·showText) · 히트스톱/흔들림 없음 · Hit 소리 0.14초 간격 (`PlayerClient`) | 팝 1.0->1.25->1.0 / 0.10초 (변경) · 1.5스터드 떠오름 0.5초 (신규) · 적 흰 번쩍 0.06초 (신규) · 히트스톱 없음 유지 |
| 2 치명타 | 노랑 "!" 팝 1.7 / 0.14초 · 흔들림 0.25 · 소리는 높은 Hit · Crit 소리는 콤보 이정표만 (`IntensityClient`) | 팝 1.0->1.6->1.15->1.0 / 0.18초 + 빨간 외곽선 (변경) · 흔들림 0.35 / 0.14초 (변경) · 히트스톱 0.03초, 0.25초에 한 번 (신규) · Crit 소리 0.38초 간격 (변경) |
| 3 처치 | 조각 + 영혼 연기 (`FxClient` K) · 흔들림 0.5 / 0.20초 + 밀림 0.18 · 치명 처치 히트스톱 0.045초 + 밀림 0.45 · 처치음 꺼짐 · 콤보 글자 팝 없음 | 콤보 글자 팝 1.0->1.3->1.0 / 0.15초 (신규) · 흰 고리 0.12초 (신규) · 처치음 다시 켬 음량 0.18, 0.18초 간격, 콤보 따라 음높이 1.0->1.3 (신규) |
| 4 리듬 0~2초 | 기본 공격 0.35초 (`Config.Player.BaseCooldown`) | 6발 중 3번째 치명타(0.70초: 팝 1.6, 흔들림 0.35/0.14초, 멈칫 0.03초) · 5번째 처치(1.40초: 흔들림 0.5/0.20초, 멈칫 없음) |

결정이 필요한 점: 처치음은 예전에 "연달아 잡을 때 거슬린다"는 의견으로 끈 것이다. 이번 시안은 음량을 낮추고 간격을 둔 채 다시 켜는 안이라, 싫으면 3번 프레임의 처치음 두 줄만 빼면 된다.
