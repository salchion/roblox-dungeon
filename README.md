# Roblox Dungeon

> 설계 / BM(상점) 구조는 [DESIGN.md](DESIGN.md) 를 보세요.

하이퍼 FPS 느낌의 성장형 슈터. 마을(로비)에서 시작해서 **던전**(웨이브 + 보스), **직선 사냥 필드**(동쪽으로 갈수록 강해짐), **허수아비 훈련장**(골드), **무기·장비 강화 + 보스 티켓 뽑기**로 강해지고, 전투력과 필드 돌파 구역을 머리 위에 달고 과시한다.

## 가장 쉬운 설치 / 업데이트: 플러그인
`Tools/DungeonUpdater.lua` 를 Studio 플러그인으로 한 번만 설치하면 된다.
1. Studio에서 `ServerStorage`에 **Script**를 만들고 `Tools/DungeonUpdater.lua` 내용을 붙여넣는다
2. Script 우클릭 → 저장/내보내기 → **로컬 플러그인으로 저장…**
3. 플러그인 탭의 **[던전 업데이트]** 버튼을 누르면 GitHub 최신 코드로 스크립트 전부를 만들어주고/덮어쓴다 (파일 목록은 `manifest.json`)
4. 끝나면 Ctrl+S 로 저장

플러그인을 쓰지 않고 직접 붙여넣을 때의 위치는 `manifest.json` 에 적혀 있다 (ReplicatedStorage: Config, Remotes, AudioIds / ServerScriptService: GameServer + Modules 폴더 / StarterPlayerScripts: PlayerClient).

## 조작
- 이동 WASD, **Shift** 달리기, **Q** 슬라이딩(2초 쿨타임, 미끄러지다 점점 느려짐), **마우스 클릭(누르고 있으면 연사)** 으로 조준 방향 공격
- **R** 자동 공격(락온): 가장 가까운 허수아비/몬스터를 자동으로 쏜다. 켠 상태에서 원하는 대상을 클릭하면 그 대상으로 고정 (배율 높은 허수아비를 골라 때릴 수 있음)
- **I** 메뉴: 캐릭터 · **가방**(장비 장착/분해/재굴림) · 무기 · **성장**(훈련소/돌파) · 퀘스트 · 업적 · 랭킹 · **상점**
- 던전 안에서 스탯 포인트: 숫자키 `1` `2` `3`

## 구역
### 로비 (마을)
- 남쪽 광장(분수, 스폰) → 북쪽 **던전 게이트** / 서쪽 **허수아비 훈련장** / 동쪽 **강화대**와 **장비 뽑기 머신** / 동쪽 끝 **필드 입구**
- 파티: 우측 패널에서 초대 → 최대 4인. 던전은 파티장만 입장시킬 수 있다

### 허수아비 훈련장 (로비 서쪽)
- 10개가 한 줄로 서 있고 **아래로 갈수록 배수가 오르며 더 크고 강해 보인다** (x1 → x30)
- 때릴 때마다 골드가 **자동으로** 들어온다 (줍기 없음)
- 배수가 높은 허수아비는 필요한 무기 강화 레벨이 있다 (`Config.Dummy.List`)

### 몬스터 7종 (던전/필드 공통, 구역·던전마다 나오는 종류가 다름)
슬라임(한 발씩) · 가시 독충(부채꼴 3발) · 박쥐(작고 빠르게 날며 연사) · 마법사 유령(멀리서 전방위 탄막) · 바위 골렘(크고 단단, 느린 큰 포탄) · 돌진 멧돼지(붉게 예고 후 돌진) · 폭탄병(달려와 자폭)

### 필드 (로비 동쪽, 직선)
- 8개 구역(초원 → 숲 → 황무지 → 사막 → 설원 → 화산 → 암흑 지대 → 심연), 동쪽으로 갈수록 몬스터가 강해진다
- 구역마다 일반 몬스터 + 엘리트(★, 확률로 티켓), 맨 끝에 **필드 보스**(티켓)
- 필드 양옆은 높은 계곡 절벽으로 막혀 있어 바깥이 보이지 않는다
- 가장 멀리 간 구역이 이름표에 `🏔 필드 N구역 돌파` 로 남는다

### 던전 (북쪽 게이트 → 선택창에서 종류 + 난이도)
- **종류 3가지**: 고블린 동굴(5웨이브, 입문) / 얼음 성채(6웨이브, 나선 탄막) / 화염 신전(7웨이브, 메테오). 각각 아레나 테마, 보스, 보스 패턴 비중이 다르다
- **난이도 3가지**: 쉬움 / 보통 / 어려움 (몬스터 체력·공격력, 골드 보상, 보스 티켓 수가 달라짐)
- 웨이브 클리어마다 30초 스탯 분배(치명타/공격속도/최대체력) → 보스
- 보스 패턴: 부채꼴 연발 / 전방위 탄막 / 나선 탄막 / 메테오(붉은 원 피하기), 체력 50% 이하에서 광폭화
- 보스를 잡으면 파티원 전원에게 **장비 뽑기 티켓** 지급 (난이도별 2/3/5장)
- 던전 아레나는 로비/필드와 겹치지 않게 아주 높은 하늘 위에 따로 만들어진다

## 성장
- **캐릭터 레벨(최대 50)**: 필드/던전에서 몬스터를 잡거나 웨이브·던전을 클리어하면 경험치(XP). 레벨이 오르면 최대 체력 +8, 공격력 +3%, 체력 완전 회복. 정보 패널의 막대에서 확인하고 이름표에도 `Lv.N`이 표시된다
- **무기 종류**: 권총(기본) / **샷건**(구매 2500G, 6발 산탄·사거리 90) / **저격총**(구매 5000G, 한 방 x4·치명타 +25%·사거리 600). 종류마다 강화 레벨이 따로 있고 메뉴(I) → 무기 탭에서 구매·교체
- **일일 퀘스트**(매일 바뀜) / **업적** → 골드·티켓 보상, 업적을 달성하면 **칭호** 해금 → 이름표에 『칭호』 표시
- **랭킹**: 광장의 랭킹판과 메뉴 랭킹 탭에 전투력 TOP 10 (전 서버 통합, Studio에서 API 접근을 켜야 동작)
- **무기 강화**(모루): 골드로 +15까지. 레벨마다 외형(색/크기/재질/파티클/궤적/빛)과 **발사체 모양**이 달라진다
- **장비**(뽑기 머신): 티켓 1장으로 갑옷(최대 체력) / 장갑(치명타) / 신발(이동속도)을 뽑는다. 등급 일반~신화, 골드로 +15까지 강화. 같거나 낮은 등급이 나오면 골드로 교환. 장비는 캐릭터에 외형으로도 보인다
- **전투력**: 무기 + 스탯 + 장비를 합친 수치. 머리 위 이름표와 리더보드에 표시된다

## 소리 넣는 법
`ReplicatedStorage > AudioIds` 스크립트에 Roblox 오디오 에셋 ID(숫자)를 적는다. 0이면 재생하지 않는다.
`Lobby` / `Dungeon` / `Boss` / `Field`(배경음악), `Shot`(총소리), `EnhanceSuccess`(강화 성공음).
`AudioIds`는 업데이트 플러그인이 덮어쓰지 않아서 한 번 적어두면 계속 유지된다.

## 밸런스 조절
`Shared/Config.lua` 의 숫자만 바꾸면 된다 (웨이브, 스탯, 강화 비용/확률, 장비 등급 효과, 가챠 확률, 필드 구역/몬스터, 허수아비 배수 등).

## 파밍 / 성장 / 상점 요약 (자세한 건 DESIGN.md)
- **필드가 메인 루프**: 구역 하나가 700 x 320 으로 아주 넓다. 몬스터가 **장비 아이템**(부위 + 등급 + 랜덤 옵션)을 떨어뜨리고, 개인 전리품 빔으로 보이며 가까이 가면 자동으로 줍는다
- **캠프**: 구역 입구마다 안전지대 + 워프 비콘. 필드에서 죽으면 가까웠던 캠프에서 부활
- **공개 이벤트**: 일정 시간마다 침공 사령관이 나타나고(하늘의 보라색 빛기둥), 같이 싸운 사람은 전리품을 받는다
- **던전**: 열쇠 필요(시간이 지나면 자동 회복, 숙제 아님). 보스 상자에서 장비를 준다
- **성장(시간이 걸림)**: 훈련소(공격/체력/치명타/이속 영구 강화) + 돌파(레벨 10/20/30/40 관문). 시간 단축권 / 훈련 슬롯 / VIP 로 가속 = BM
