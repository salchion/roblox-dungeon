# Roblox Dungeon

> 설계 / BM(상점) 구조는 [DESIGN.md](DESIGN.md) 를 보세요.

하이퍼 FPS 느낌의 성장형 슈터. 마을(로비)에서 시작해서 **던전**(웨이브 + 보스), **직선 사냥 필드**(동쪽으로 갈수록 강해짐), **허수아비 훈련장**(골드), **무기·장비 강화 + 보스 티켓 뽑기**로 강해지고, 전투력과 필드 돌파 구역을 머리 위에 달고 과시한다.

## 가장 쉬운 설치 / 업데이트: 플러그인
`Tools/DungeonUpdater.lua` 를 Studio 플러그인으로 한 번만 설치하면 된다.
1. Studio에서 `ServerStorage`에 **Script**를 만들고 `Tools/DungeonUpdater.lua` 내용을 붙여넣는다
2. Script 우클릭 → 저장/내보내기 → **로컬 플러그인으로 저장…**
3. 플러그인 탭의 **[던전 업데이트]** 버튼을 누르면 GitHub 최신 코드로 스크립트 전부를 만들어주고/덮어쓴다 (파일 목록은 `manifest.json`)
4. 끝나면 Ctrl+S 로 저장

플러그인을 쓰지 않고 직접 붙여넣을 때의 위치는 `manifest.json` 에 적혀 있다 (ReplicatedStorage: Config, Remotes, AudioIds / ServerScriptService: GameServer + Modules 폴더 / StarterPlayerScripts: PlayerClient).

## 조작
- 이동 WASD, **Shift** 달리기, **Q** 슬라이딩(2초 쿨타임, 미끄러지다 점점 느려짐), **마우스 클릭(누르고 있으면 연사)** 으로 조준 방향 공격
- **R** 자동 공격(락온): 가장 가까운 허수아비/몬스터를 자동으로 쏜다. 켠 상태에서 원하는 대상을 클릭하면 그 대상으로 고정 (배율 높은 허수아비를 골라 때릴 수 있음)
- **I** 메뉴: 캐릭터 · **가방**(장비 장착/분해/재굴림) · 무기 · **성장**(훈련소/돌파) · 퀘스트 · 업적 · 랭킹 · **상점**
- **스킬(필드/던전)**: `Z` 에너지 방벽(3초 무적) · `F` 충격파(조준한 곳 폭발) · `C` 응급 치료(나+파티원 회복) · `V` 궁극기 데드아이(공격할수록 게이지가 차고, 가득 차면 주변 모든 적을 한 번에 저격). 하단 스킬바에 쿨타임 표시
- 던전 특성 고르기: 웨이브 클리어 때 나오는 카드 3장 중 `1` `2` `3`

## 구역
### 로비 (마을)
- 남쪽 광장(분수, 스폰) → 북쪽 **던전 게이트** / 서쪽 **허수아비 훈련장** / 동쪽 **강화대**와 **장비 뽑기 머신** / 동쪽 끝 **필드 입구**
- 파티: 우측 패널에서 초대 → 최대 4인. 던전은 파티장만 입장시킬 수 있다

### 허수아비 훈련장 (로비 서쪽)
- 10개가 한 줄로 서 있고 **아래로 갈수록 배수가 오르며 더 크고 강해 보인다** (x1 → x30)
- 때릴 때마다 골드가 **자동으로** 들어온다 (줍기 없음)
- 배수가 높은 허수아비는 필요한 **캐릭터 레벨**이 있다 (무기 공격력과 무관) (`Config.Dummy.List`)

### 몬스터 7종 (던전/필드 공통, 구역·던전마다 나오는 종류가 다름)
슬라임(한 발씩) · 가시 독충(부채꼴 3발) · 박쥐(작고 빠르게 날며 연사) · 마법사 유령(멀리서 전방위 탄막) · 바위 골렘(크고 단단, 느린 큰 포탄) · 돌진 멧돼지(붉게 예고 후 돌진) · 폭탄병(달려와 자폭)

### 필드 (로비 동쪽, 직선)
- 8개 구역(초원 → 숲 → 황무지 → 사막 → 설원 → 화산 → 암흑 지대 → 심연), 동쪽으로 갈수록 몬스터가 강해진다
- 구역마다 일반 몬스터 + 엘리트(★, 확률로 티켓), 맨 끝에 **필드 보스**(티켓)
- 필드 양옆은 높은 계곡 절벽으로 막혀 있어 바깥이 보이지 않는다
- 가장 멀리 간 구역이 이름표에 `🏔 필드 N구역 돌파` 로 남는다

### 던전 (북쪽 게이트 → 선택창에서 종류 + 난이도)
- **종류 3가지**: 고블린 동굴(5웨이브, 입문) / 얼음 성채(6웨이브, 나선 탄막) / 화염 신전(7웨이브, 메테오). 각각 아레나 테마, 보스, 보스 패턴 비중이 다르다
- **난이도 3가지**: 쉬움 / 보통 / 어려움 (몬스터 체력·공격력, 골드 보상, 보스 티켓 수가 달라짐)
- 웨이브 클리어마다 **특성 카드 3장 중 1장 선택**(뱀파이어 서바이벌식, 그 던전 동안만 유지): 분산탄(탄이 부채꼴로 +1발) · 관통탄 · 폭발탄 · 연쇄 번개 · 흡혈 · 강타 · 속사 · 급소 · 강인함 → 보스
- **던전 지형(로그라이크식)**: 들어갈 때마다 배치 유형(동굴 군락 / 구불구불한 협곡 길 / 허브와 갈래 길)과 방·길의 모양이 새로 만들어진다. 절벽으로 둘러싸인 길과 방 안에 언덕(올라가기)·구덩이(떨어지기)가 흩어지고, 입구 반대편 끝(또는 한 갈래)이 보스방이다
- 보스 패턴: 부채꼴 연발 / 전방위 탄막 / 나선 탄막 / 메테오(붉은 원 피하기), 체력 50% 이하에서 광폭화
- 보스를 잡으면 파티원 전원에게 **장비 뽑기 티켓** 지급 (난이도별 2/3/5장)
- 던전 아레나는 로비/필드와 겹치지 않게 아주 높은 하늘 위에 따로 만들어진다

## 추가 콘텐츠 / 연출
- **연속 처치 콤보**: 4초 안에 계속 처치하면 콤보가 쌓여 공격력 최대 +50%, 처치마다 궁극기 게이지 +4. 화면 오른쪽에 콤보 표시
- **던전 변이**: 던전마다 65% 확률로 거대화 / 신속 / 떼거지 / 황금의 날 / 광폭 중 하나가 붙는다 (위험 + 보상 증가). 상단 배너에 표시
- **출석 보상**: 하루 한 번 접속하면 자동 지급, 연속 출석할수록 커지는 7일 주기 (골드 / 열쇠 / 티켓)
- **레이더**: 필드/던전에서 오른쪽 아래 원형 지도에 주변 몬스터가 표시된다 (빨강 일반 / 노랑 엘리트 / 보라 보스 / 금색 황금 고블린). 위쪽이 카메라 방향이고 범위 밖은 가장자리에 흐리게 나온다 — 지형이 복잡한 던전에서 길 찾기용
- **황금 고블린**: 필드에 몇 분마다 나타나 플레이어에게서 도망치는 희귀 몬스터 (75초 뒤 사라짐). 잡으면 골드 대박 + 전리품 3개. 퀘스트/업적/칭호 연동
- **스킬 퀘스트/업적**: 스킬 사용 횟수 업적과 칭호 추가
- **전투 연출**: 피격 시 화면이 붉게 번쩍이고 체력이 30% 미만이면 붉은 경고, 몬스터 처치 시 폭발 이펙트와 골드 표시

## 더 깊은 콘텐츠
- **타격감**: 맞은 몬스터가 하얗게 번쩍이고, 적중하면 조준점이 색을 바꾼다 (치명타/처치는 붉게 + 카메라 흔들림). `AudioIds` 에 `Hit`/`Kill`/`Skill` 소리 ID를 넣으면 적중음/처치음/스킬음이 난다
- **세트 장비**: 영웅 이상 장비에 세트(사냥꾼/수호자/질풍/현자)가 붙을 수 있다. 같은 세트 2부위 / 3부위 착용 시 보너스. 가방에서 착용 현황(n/3)과 보너스를 확인
- **유니크 장비**: 신화 등급에서 일정 확률로 고정 효과 (분열의 총탄 = 탄 +1발, 시간 왜곡 = 스킬 쿨타임 -25%, 학살자, 행운의 별)
- **장비 비교**: 가방에서 현재 착용 장비보다 점수가 높으면 ▲ 낮으면 ▼ 표시
- **스킬 강화**: 메뉴(I) → 스킬 탭에서 골드로 스킬 레벨업 (Lv.10까지, 효과 증가 + 쿨타임 감소)
- **펫**: 메뉴 → 펫 탭에서 알 부화 (4000G). 8종 / 4등급, 같은 펫이 또 나오면 펫 레벨업. 장착한 펫은 캐릭터를 따라다니며 공격력·치명타·경험치·이동속도·쿨타임 감소 중 하나를 준다
- **무한의 탑**: 던전 선택창의 4번째 던전. 끝없는 웨이브(매 층 특성 선택), 5층마다 티켓, 최고 층이 기록되고 업적/칭호 연동

## 보스 / 협동 / 최종 목표 / 편의
- **보스 패턴 2종 추가**: 대지 강타(보스를 중심으로 퍼지는 충격파 고리 — 점프로 피함) · 소환(쫄병을 불러냄). 던전 종류마다 비중이 다르다
- **파티 시너지**: 70 스터드 안의 파티원 1명당 공격력 +4% (최대 3명)
- **환생**: 레벨 50에서 메뉴 → 캐릭터 탭의 환생하기. 레벨이 1로 돌아가고 영구 공격력 +5% (최대 10회). 이름표에 🌟 표시, 업적/칭호 연동
- **도움말 / 설정 (H)**: 조작법과 게임 흐름 안내(접속하면 한 번 자동으로 열림), 음악 볼륨 / 화면 흔들림 / 레이더 on-off
- **모바일**: 스킬 칸을 터치해서 사용

## 첫 1~5분 (튜토리얼 미션)
처음 접속하면 상단에 미션 바와 목표 위치의 **노란 빛기둥**이 나타나 한 단계씩 안내한다. 미션을 끝낼 때마다 보상이 바로 터진다.
1. 허수아비 8번 쏘기 (+300G) → 2. 모루에서 무기 강화 (무료·100%) (+200G) → 3. 한 번 더 강화, **+3이 되면 총이 진화** (티켓 +1) → 4. 뽑기 머신에서 장비 뽑기 (+1500G) → 5. 필드에서 몬스터 5마리 (열쇠·티켓·경험치) → 6. 던전 도전 (+3000G, 티켓 2)
- 초반(레벨 6까지) 경험치 x3, 허수아비 골드 2배로 레벨업과 골드가 빠르게 오른다
- 이미 진행한 유저(레벨 5 이상)는 튜토리얼을 건너뛴다. 수치/문구는 `Config.Tutorial` 에서 바꾼다

## 성장
- **캐릭터 레벨(최대 50)**: 필드/던전에서 몬스터를 잡거나 웨이브·던전을 클리어하면 경험치(XP). 레벨이 오르면 최대 체력 +8, 공격력 +3%, 체력 완전 회복. 정보 패널의 막대에서 확인하고 이름표에도 `Lv.N`이 표시된다
- **무기 종류**: 권총(기본) / **샷건**(구매 2500G, 6발 산탄·사거리 90) / **저격총**(구매 5000G, 한 방 x4·치명타 +25%·사거리 600). 종류마다 강화 레벨이 따로 있고 메뉴(I) → 무기 탭에서 구매·교체
- **일일 퀘스트**(매일 바뀜) / **업적** → 골드·티켓 보상, 업적을 달성하면 **칭호** 해금 → 이름표에 『칭호』 표시
- **랭킹**: 광장의 랭킹판과 메뉴 랭킹 탭에 전투력 TOP 10 (전 서버 통합, Studio에서 API 접근을 켜야 동작)
- **무기 진화**(모루): 골드로 +15까지. +0 권총 → +3 리볼버 → +6 라이플 → +9 핸드캐논 → +12 **로켓 런처** → +15 레일건처럼 단계마다 **이름과 총 모양, 발사체**가 바뀐다 (샷건/저격총도 각자 6단계). 강화창에서 **다음 진화 모습을 3D로 미리 볼 수 있다**
- **장비**(뽑기 머신): 티켓 1장으로 갑옷(최대 체력) / 장갑(치명타) / 신발(이동속도)을 뽑는다. 등급 일반~신화, 골드로 +15까지 강화. 같거나 낮은 등급이 나오면 골드로 교환. 장비는 캐릭터에 외형으로도 보인다
- **전투력**: 무기 + 스탯 + 장비를 합친 수치. 머리 위 이름표와 리더보드에 표시된다

## 소리 넣는 법 (배경음악 / 효과음)
`ReplicatedStorage > AudioIds` 스크립트에 Roblox 오디오 에셋 ID(숫자)를 적는다. 0이면 재생하지 않는다.
- `Lobby`(마을) / `Field`(필드 사냥) / `Dungeon`(던전) / `Boss`(보스전) 배경음악, `Shot`(총소리), `EnhanceSuccess`(강화 성공음)
- 구역을 옮기면 음악이 부드럽게 바뀐다. 게임 중 **M** 키로 음악을 켜고 끈다. `Field` 가 0이면 마을 음악이 필드에서도 계속 나온다
- **ID 찾는 법**: Studio 왼쪽 `도구 상자`(Toolbox) → 위쪽 **오디오** 탭 → "battle", "epic", "village" 처럼 검색 → 마음에 드는 곡을 눌러 미리 듣고 **우클릭 → Copy Asset ID**
- 작성자가 **Roblox** 인 곡이 모든 플레이어에게 재생되어 가장 안전하다 (남이 올린 비공개 오디오는 내 게임에서 안 나올 수 있다)
- 재생이 되는지 확인: Studio 아래 명령창에 `local s = Instance.new("Sound", workspace); s.SoundId = "rbxassetid://여기에ID"; s:Play()` 를 넣고 Enter
- `AudioIds`는 업데이트 플러그인이 덮어쓰지 않아서 한 번 적어두면 계속 유지된다

## 밸런스 조절
`Shared/Config.lua` 의 숫자만 바꾸면 된다 (웨이브, 스탯, 강화 비용/확률, 장비 등급 효과, 가챠 확률, 필드 구역/몬스터, 허수아비 배수 등).

## 파밍 / 성장 / 상점 요약 (자세한 건 DESIGN.md)
- **필드가 메인 루프**: 구역 하나가 700 x 320 으로 아주 넓다. 몬스터가 **장비 아이템**(부위 + 등급 + 랜덤 옵션)을 떨어뜨리고, 개인 전리품 빔으로 보이며 가까이 가면 자동으로 줍는다
- **캠프**: 구역 입구마다 안전지대 + 워프 비콘. 필드에서 죽으면 가까웠던 캠프에서 부활
- **공개 이벤트**: 일정 시간마다 침공 사령관이 나타나고(하늘의 보라색 빛기둥), 같이 싸운 사람은 전리품을 받는다
- **던전**: 열쇠 필요(시간이 지나면 자동 회복, 숙제 아님). 보스 상자에서 장비를 준다
- **성장(시간이 걸림)**: 훈련소(공격/체력/치명타/이속 영구 강화) + 돌파(레벨 10/20/30/40 관문). 시간 단축권 / 훈련 슬롯 / VIP 로 가속 = BM
