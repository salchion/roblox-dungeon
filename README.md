# Roblox Dungeon — Gear Rush

> 성장 / 드롭 / 경제의 기준 문서는 [GAME_SYSTEMS.md](GAME_SYSTEMS.md), 골드 공식은 [ECONOMY.md](ECONOMY.md), 설계 노트는 [DESIGN.md](DESIGN.md), 던전 깊이는 [DUNGEON_DEPTH.md](DUNGEON_DEPTH.md).

하이퍼 FPS 느낌의 성장형 슈터. 마을(로비)에서 시작해서 **필드 8구역**(동쪽으로 갈수록 강해짐)을 밀고, **던전 깊이**와 **보스 러시**로 끝없이 내려가며, **무기 50종 · 장비 6부위 · 세트 효과 · 스킬 · 특성 · 펫**으로 강해진다. 전투력과 돌파 구역을 머리 위에 달고 과시한다.

게임 인트로에서 쓰는 이름은 **Gear Rush** ("Your gear rush starts now"). 저장소 / 스크립트 이름은 예전 그대로 `Dungeon*` 을 쓴다.

## 가장 쉬운 설치 / 업데이트: 플러그인
`Tools/DungeonUpdater.lua` 를 Studio 플러그인으로 한 번만 설치하면 된다.
1. Studio에서 `ServerStorage`에 **Script**를 만들고 `Tools/DungeonUpdater.lua` 내용을 붙여넣는다
2. Script 우클릭 → 저장/내보내기 → **로컬 플러그인으로 저장…**
3. 플러그인 탭의 **[던전 업데이트]** 버튼을 누르면 GitHub(`main`) 최신 코드로 스크립트 전부(152개)를 만들어주고/덮어쓴다 (파일 목록은 `manifest.json`)
4. 끝나면 Ctrl+S 로 저장

플러그인을 쓰지 않고 직접 붙여넣을 때의 위치는 `manifest.json` 에 적혀 있다 (ReplicatedFirst: BootCover / ReplicatedStorage: Config · SkillTreeData · Remotes · 번역(Loc_*) · KoData 등 38개 / ServerScriptService: GameServer + Modules 폴더 57개 / StarterPlayerScripts: 클라이언트 55개).

## 조작
- 이동 **WASD** (달리기 키 없이 항상 같은 속도로 달린다), **Q** 대시(2회 연속 / 3초마다 1회 충전, 공중에서도 가능), **마우스 클릭(누르고 있으면 연사)**
- **R** 자동 공격(락온): 가장 가까운 적을 자동으로 쏜다. 켠 상태에서 대상을 클릭하면 그 대상으로 고정
- **2단 점프**: 공중에서 점프 키를 한 번 더
- **I** 메뉴: 캐릭터 · 가방 · 무기 · 성장(훈련/스킬/특성/펫) · 퀘스트 · 업적 · 랭킹 · 상점 · 설정
- **스킬**: `C` 응급 치료(나+파티원 회복) · **`F` 블레이드 블룸**(2.5초간 단검이 휘돌며 주변 적을 베고, 움직이며 쏠 수 있다) · `V` 데드아이(공격할수록 게이지가 차고, 가득 차면 가장 큰 적에게 미사일 16발 집중)
- **T** 레벨 스탯 창 · **P** 펫 창 · **H** 설정/도움말 · **M** 음악 on/off · **K** 사운드 테스트(Studio)
- 모바일: 화면 버튼으로 이동 / 공격 / 스킬

## 구역
### 로비 (마을)
- 남쪽 광장(분수, 스폰) → 북쪽 **던전 게이트(1개)** / 서쪽 **허수아비 훈련장** / 동쪽 **강화대·뽑기 머신·휴식 구역** / 동쪽 끝 **필드 입구**
- 파티: 우측 패널에서 초대 → 최대 4인. 던전은 파티장만 입장시킬 수 있다. 가까운 파티원 1명당 공격력 +4% (최대 3명)

### 허수아비 훈련장 (로비 서쪽)
- **연습용이다. 때려도 골드는 없다** (직접 쏘는 골드는 없앴다). 대미지 숫자 / DPS 를 확인하는 곳.
- 방치 수입은 따로 있는 **휴식 구역** 원 안에 서 있으면 쌓인다 (`Config.Idle`: 접속 중 = 활동 수입의 22%, 오프라인은 그 60%, 기본 한도 4시간)

### 던전 (북쪽 게이트 하나 · 깊이 시스템)
- **입구는 하나.** 들어갈 때마다 레벨이 맞는 종류 중 하나가 무작위로 나온다: 고블린 동굴(5웨이브, Lv.1~) / 얼음 성채(6웨이브, Lv.14~) / 화염 신전(7웨이브, Lv.26~). 깊이 기록은 종류와 상관없이 하나.
- 게이트에서 깊이를 고르고 입장한다. 못 깬 깊이로는 못 들어가고(최고 깊이 +1까지), 깊이가 깊을수록 몬스터가 강해지고 **보스 상자의 등급 · 유니크 확률 · 보상**이 오른다 (체력 ×1.22, 피해 ×1.08, 골드 ×1.15, 경험치 ×1.12 / 한 칸당).
- 웨이브를 버티는 구조. 6초마다 랜덤 강화 / 패널티가 터지고(같은 갈래를 계속 받으면 폭발/번개/관통이 3단계까지 올라가 APOCALYPSE · THUNDER GOD · BULLET HELL 로 이어진다), 보스는 들어갈 때마다 광폭한 / 비전의 / 거대한 / 군단장 중 하나.
- 입장: 하루 무료 3회 + 열쇠(깊이 1~10 = 1, 11~25 = 2, 26+ = 3). 열쇠는 시간이 지나도 차지 않고 필드 군주 드랍으로만 나온다 (최대 30개).
- **변이**(90%): 거대화 / 신속 / 떼거지 / 황금의 날 / 광폭 / 칠흑 / 짙은 안개 / 핏빛 달 / 엘리트의 날 — 위험이 클수록 보상 증가.
- **피버 던전**: 필드 거신을 잡으면 황금 균열이 열린다. 40초 동안 약한 몬스터가 쏟아지고 골드·경험치 ×8, 끝나면 황금 상자 장비 + 티켓. 쿨타임 10분, 하루 5회.

### 필드 (로비 동쪽, 직선)
- 8개 구역(초원 → 숲 → 폐허 → 사막 → 설원 → 용암 → 어둠 → 심연), 구역 길이 1,400 (1구역은 340) × 폭 320
- 구역마다 일반 몬스터(**13종** 중 조합) + 엘리트 3 + 끝에 **구역 군주**. 관문(처치 40~140마리)을 열어야 다음 구역
- 구역 입구마다 캠프(안전지대 / 워프 / 부활). 워프 요금 `100 × 구역²` (마을행 무료)
- **현상금**: 2~3분마다 큰길 밖에 엘리트 3마리 무리 → 2분 안에 잡으면 골드 ×3 + 티켓 + 장비
- **거신(월드 보스)**: 4~6분마다 한 구역에 나타난다 (군주급 체력 ×240, 골드 ×70). 함께 잡은 사람 모두 보상
- **황금 고블린**: 몇 분마다 나타나 도망친다. 잡으면 골드 대박 + 전리품
- **공습**: 경보 후 폭격기가 지나가며 폭탄을 떨군다

### 보스 러시 (심연 · 필드 8구역 클리어 후)
- 마을 동쪽 분홍 포탈. 하루 2회, 최대 10분. 보스가 점점 빨리 나오고(15초 → 8초) 쌓일수록 위험.
- 점수 = 버틴 시간 × 준 피해 (주간 랭킹). 등급 보상 브론즈 ~ 미식: 골드 200 ~ 90,000 + 티켓 + 시간 단축권

### 최후의 군주
- 8구역 군주를 잡으면 8구역 끝에 포탈. 체력 5,600만, 3단계 패턴. 보상 골드 300만 + 티켓 40, 주간 첫 처치에 세트+유니크 확정 신화 1개

## 성장
- **캐릭터 레벨(최대 400)**: 사냥·던전 경험치. 레벨당 공격력 +3%(50까지) → +0.6%, 체력 +8(200까지) → +25. `T` 레벨 스탯(이동·사거리·더블샷·쿨감·치명피해, 무료 재배분), 400 이후 **패러건**(공격·치명·치명피해·보스피해 각 100포인트)
- **특성(탈렌트)**: 레벨 5마다 1점, 최대 20점. 🩸 Blood / 🪓 Execute / 💨 Swift 세 갈래 (세 길 중 두 길을 끝까지). 마을에서 골드로 초기화
- **무기 50종 / 1,055단계**: 10개 시대 × 5종류(저격총형 라이플 · 샷건 · 로켓 런처 · 레일건 · 마법책). 첫 시대는 +15마다 새 형이 열리고(+60에 5종 전부), 이후엔 원하는 형을 골라 쓴다. 모루에서 골드로 강화하면 무기마다 15~24단계를 채운 뒤 다음 무기로 진화하고, 시대가 바뀌면 탄·꼬리·착탄 연출과 외형이 크게 바뀐다. 도감(무기 탭)에서 발사 모습을 미리 볼 수 있다
- **장비 6부위**: 갑옷(체력) · 장갑(치명) · 신발(이동) · 투구(공격력) · 반지(쿨감) · 목걸이(행운). 등급 일반~신화, 골드로 **+30**까지 강화 (실패해도 단계는 안 내려간다). 신화는 30% 확률로 **유니크**(분열탄·시간왜곡·도살자·행운의별·도탄·흡혈·거인학살자·아드레날린·천둥탄·잭팟·방벽)
- **세트 장비 + 세트 효과**: 구역마다 그 구역에서만 떨어지는 세트(초원의 수호 … 심연의 지배)가 2부위/3부위 보너스를 준다. **세트 장비를 끼면 세트 효과가 저절로 켜진다** — 단계 = 골드로 올린 단계 + 낀 세트 부위 + "+1" 옵션 (최대 6). 골드 단계는 그 구역 군주를 잡으면 열린다. 슬롯은 1개 → 3구역 클리어 2개 → 7구역 3개
- **스킬 4종**(응급 치료 C / 블레이드 블룸 F / 데드아이 V / 기운 집중 패시브): 골드+시간으로 Lv.10, Lv.3·5·7·10에서 두 갈래 중 하나를 고른다. 스킬끼리 시너지(디아블로2식)도 있다
- **훈련 10칸**: 공격 · 체력 · 치명 · 속도 / 더블샷 · 치명피해 · 골드감각 · 질긴 피부 / 공격속도 · 회복력. 골드+시간(칸마다 최대 4~30단계), 시간 단축권으로 줄인다
- **펫 Lv.15**: 골드로 해금 후 레벨업. 경험치·공격·치명·자동 줍기·수호(무적)·공속·사냥 표식·대각성. 외형 9종은 군주 처치 / 칭호로 해금
- **전투력**: 무기 + 레벨 + 스탯 + 장비/훈련/펫. 이름표와 랭킹에 표시된다

## 뽑기 (장비, 티켓)
- 1회 = 티켓 1장, 10연 가능. 일반 55 / 희귀 28 / 영웅 12 / 전설 4 / 신화 1%, 50회 전설 · 150회 신화 천장
- 같은/더 좋은 장비가 나오면 골드로 교환. 구역을 지정하면 그 구역 세트로 뽑히고 골드가 추가된다

## 인벤토리 (I → 가방)
가운데에 내 캐릭터가 3D로 돌고(입은 장비·든 총 그대로), 양옆 장비 칸 6개 + 무기 칸에 등급 색 윤곽선. 오른쪽에 선택한 장비의 옵션 / 세트 / 유니크 / 비교가 나오고, 아래는 가방 칸 격자. 세트 완성 · 더 강한 장비 · 세트 효과 단계 변화를 한 화면에서 비교할 수 있다.

## 연출 · 편의
- **연속 처치 콤보**: 4초 안에 계속 처치하면 콤보가 쌓여 공격력 최대 +50%
- **레이더**: 필드/던전 오른쪽 아래 원형 지도 (일반/엘리트/보스/황금 고블린)
- **출석 보상**: 하루 한 번 접속하면 자동 지급, 7일 주기 (골드 / 열쇠 / 티켓)
- **명예의 전당**: 랭킹판 앞에 전 서버 최강 3명 아바타 + 이번 주 챔피언
- **도감(Codex)**: 가이드 탭에서 구역별 몬스터 · 군주 · 관문 · 장비 드롭 확률(행운 반영) · 세트와 세트 효과를 게임 카드로 본다
- **다음 목표 패널**: 지금 가장 가까운 목표를 한 줄로 (다음 무기 진화까지 필요 골드 / 레벨업 경험치 / 던전 열쇠 / 뽑기 티켓 / 돌파 구역)
- **서버 전체 알림**: 무기 진화 / 전설 펫 / 최후의 군주 처치 등

## 소리
- `ReplicatedStorage > AudioIds` 에 Roblox 오디오 ID(숫자)를 적는다. 0이면 재생하지 않는다 (`Lobby` / `Field` / `Dungeon` / `Boss` 음악, `Shot`, `EnhanceSuccess`)
- 무기 종류마다 소리를 피치/잔향/에코/왜곡/겹치기로 가공한다 (`Shared/SoundBank.lua` SPECS). Studio에서 **K** 로 사운드 테스트 창을 열어 후보 ID를 바로 들어 볼 수 있다
- `AudioIds` 는 업데이트 플러그인이 덮어쓰지 않아서 한 번 적어두면 계속 유지된다

## 언어 (7개)
한국어 · 日本語 · Deutsch · Français · Español · Português · 中文(简体). Roblox 로케일에 맞춰 자동 적용된다.

## 파밍 / 성장 요약 (자세한 건 GAME_SYSTEMS.md)
- **필드가 메인 루프**: 골드 + 경험치 + 구역 세트 장비. 뒤 구역일수록 등급이 확 좋아진다 (8구역 신화 12%)
- **던전은 신화 · 유니크 파밍**: 깊이가 곧 성장 축이고, 상자 확률이 눈에 보이게 오른다
- **성장은 시간이 걸린다**: 훈련 / 스킬 / 펫은 대기 시간이 있고, 시간 단축권 · 훈련 슬롯 · VIP 로 가속 = BM
- **BM 원칙**: 장비는 팔지 않는다. 돈은 시간(대기 · 열쇠 · 부스터 · 방치 한도)을 산다. PvE 전용
